## Deskripsi Singkat
Toko Sembako Ariesta adalah aplikasi web berbasis Node.js dan Express.js yang dikembangkan untuk membantu pemilik toko (Ibu Aries) mengelola data produk sembako secara mandiri melalui dashboard admin yang terlindungi autentikasi, serta menyediakan fitur interaktif "Tanya AI" (dummy) bagi pelanggan.

## Cara Menjalankan Proyek Secara Lokal
1. Clone repository ini ke komputer Anda.
2. Buka terminal pada folder proyek, lalu install dependencies:
   ```bash
   npm install

## Jalankan server via nodemon:
npm run dev
